# 首播說明會（給負責人看）

這一頁是 2026-11-03 的定時播映說明會，網址是 `/premiere`。
它不會改首頁那筆 NT$399 前導課，也不會自己收錢。真正扣款仍走舊的 Sites 後端。

預設打不開。環境變數 `PREMIERE_PAGE_ENABLED` 不是 `1` 時，`/premiere` 一律是 404，占位文案不會先公開。

畫面上標成 **【待 Elsa 確認】** 的句子都還不是定稿。這些句子還在時，就算把付款開關打開，按鈕也不會送出訂單。

## 這版有什麼

- 打開頁面就是播放器。開播前，倒數在影片框裡。開播後用伺服器時間決定播放進度。晚到的人從「現在播到哪」開始，不能快轉，暫停或斷線後也會對回現在的進度。播完是結束畫面。
- 這一頁**不再收集報名**。來看的人是已經填過前導課報名表的人。
- 手機先靜音自動播放，點一下才開聲音。手機是上面影片、下面主持人、再下面兩個分頁。電腦是左邊大影片、右邊分頁。
- 「即時訊息」依影片時間出現。晚到或重新整理會看到已經到點的訊息。出廠是空的，沒有範例。負責人在 `/premiere/messages` 自己編，存到舊後端。
- 「產品列表」在設定的時間之前是鎖住的。到點會自己切過去，出現 NT$39,800 的課程卡。「我要下單」打開底部表單（姓名、手機、Email），再走原本的統一金流。金額仍由舊後端決定，Vercel 會核對是不是 39800。
- 播完之後，下單按鈕換成已結束的說明。

## 這版故意沒做

- 沒有把金流搬到 Vercel，也沒有在 Vercel 新增寄信程式。付款成功信仍由舊後端寄出；NT$399 維持原信，NT$39,800 的句子在 `patches/premiere-sites-v25.patch`。
- 沒有 Neon 資料庫。名單和訊息都在舊後端的 Cloudflare D1。
- 沒有觀眾人數、沒有假的購買通知、沒有讓觀眾打字的輸入框。
- 沒有把「直播」兩個字用在這一頁。對外說法是「首播」或「定時播映」。負責人說的「偽互動」就是這份依時間出現的訊息，不是即時聊天。

## 要設定的環境變數（只寫名稱）

請有 **Vercel 專案 `win-lecturer-20261018`** 權限的人，到該專案的環境變數設定。不要把金鑰貼到聊天或檔案裡。

| 名稱 | 誰設定 | 什麼時候 |
|---|---|---|
| `BUNNY_STREAM_VIDEO_ID` | Vercel 管理員 | 現在就可以。Bunny 影片編號，長得像一串帶減號的英文數字。 |
| `BUNNY_STREAM_CDN_HOSTNAME` | Vercel 管理員 | 現在就可以。Bunny 的播放網址，通常是 `vz-` 開頭、`.b-cdn.net` 結尾，不要加 `https://`。 |
| `PREMIERE_PAGE_ENABLED` | Vercel 管理員 | 值寫 `1` 之後，`/premiere` 才看得到。沒設就是 404。 |
| `PREMIERE_CHECKOUT_ENABLED` | Vercel 管理員 | **最後才設。** 值寫 `1`。文案裡還有「待 Elsa 確認」時，按鈕仍不會送出訂單。 |
| `PREMIERE_ALLOWED_ORIGINS` | Vercel 管理員 | 可不設。只放寬「登記」「進入時間」和「儲存即時訊息」的來源網址，不放寬付款。若要在預覽網址試設定頁，把完整網址填在這裡，多個用逗號分開。 |

不要在 Vercel 新增或修改 `PAYUNI_MER_ID`、`PAYUNI_HASH_KEY`、`PAYUNI_HASH_IV`、`RESEND_API_KEY`、`RESEND_FROM`、`RESEND_REPLY_TO`。這些仍只放在舊 Sites 專案。

舊 Sites 專案要另外新增一個名稱：`PREMIERE_EXPORT_TOKEN`。做法寫在 `patches/README.md`。

設定影片變數後要重新部署，這一頁才看得到影片。兩個都空著時，開播後會顯示「影片尚未設定」，其餘功能仍可看。

若 Bunny 有打開 Token 驗證，這版播不了。請先讓這支影片可以用公開的 HLS 網址播放，或先關掉那支影片的 Token 驗證。這版不會讀取簽章金鑰。

## 不用 Neon

這一版不需要建立 Neon，也不需要 Postgres。請不要為了說明會去接新的資料庫。

## 怎麼改時間、影片長度、購買按鈕出現的時間

只改一個檔案：`vercel-win/lib/premiere/config.ts`。

- `startAt`：首播開始。現在是 `2026-11-03T19:30:00+08:00`（台北時間 11 月 3 日 19:30）。
- `durationSeconds`：影片長度，單位是秒。現在是 90 分鐘（5400 秒）。請改成實際影片長度，否則結束畫面會提早或延後。
- `offerAt`：產品列表解鎖的時間。現在是當天 20:30。
- `hostName`、`hostNote`、`originalPriceLabel`：主持人與畫面上的原價。原價只負責顯示，真正扣款仍是 39800。

改完要重新部署。播放進度以網站伺服器的時間為準，不是觀眾電腦的時間。

場次代碼 `sessionCode` 現在是 `premiere-2026-11-03`。這是首播自己的代碼，不是首頁前導課的四個場次。舊後端的 patch 只讓正式課程使用它。

## 怎麼改畫面上的文字和價格

同一個檔案 `vercel-win/lib/premiere/config.ts`。

- `priceTwd`：畫面上的價格，現在是 `39800`。這只負責顯示。
- `copy`：說明會頁的句子。
- `payment`：付款結果頁在正式課程時用的句子，含等待中、失敗和讀不到訂單。NT$399 的句子沒有改。方案以舊後端訂單上的代碼為準，不看網址參數。

真正扣到的金額不看這個數字，而看舊後端允許清單裡的 `fullcourse`（目前也是 39800）。若要改價，兩處都要改，而且要先發布舊後端。說明會按鈕只會送出方案代碼 `fullcourse`，不會把金額交給瀏覽器決定。

## 付款按鈕為什麼現在按不下去

在 `PREMIERE_CHECKOUT_ENABLED` 設成 `1`、而且文案與商品名稱都拿掉「待 Elsa 確認」之前，到了優惠時間也只會看到「即將開放」，不會送出訂單。若後端還沒發布、建單金額不是 39800，Vercel 會擋下並顯示「正式課程付款尚未開放」，不會把 399 的付款網址交出去。

## 怎麼編即時訊息

網址是 `/premiere/messages`。和首播頁一樣，要先把 `PREMIERE_PAGE_ENABLED` 設成 `1` 才看得到。

這一頁給負責人自己用，不需要改程式：

1. 貼上舊後端的 `PREMIERE_EXPORT_TOKEN`（和匯出名單同一組）。它只存在這台瀏覽器，不會寫進 Vercel。
2. 新增、修改或刪除每一則：顯示名稱、類型（老師公告／學員回饋／一般留言）、出現時間（`00:00:00`）、內容、頭像網址（可空）。
3. 在「預覽」填一個時間，看那個時間點會出現哪些訊息。
4. 按「儲存到後端」。儲存會整份取代舊清單。也可以匯出、匯入 CSV，匯入之後還要再按儲存。

出廠沒有任何訊息。請不要把試看用的句子存進去。

儲存會經過 Vercel，再寫進舊 Sites 的 D1。舊後端的 patch 還沒發布時，讀取會是空的，儲存會失敗。正式網站和 `https://win-lecturer-20261018.vercel.app` 可以儲存。其他預覽網址要先寫進 `PREMIERE_ALLOWED_ORIGINS`。付款網址沒有因此放寬。

選這個做法，是因為 11/3 之前負責人要能自己改字，而且改完不用重新部署。單一 JSON 檔每次都要改程式再發布，來不及。

付款只接受兩個網址：`https://2027course.win-lin.com` 和 `https://win-lecturer-20261018.vercel.app`。預覽網址不能建立訂單。這是原本前導課就有的保護，這版沒有放寬。

請一定照這個順序，否則觀眾可能被收成 NT$399：

1. 有 Sites 權限的人先照 `patches/README.md` 發布舊後端，並確認新訂單金額是 39800。
2. 再到 Vercel 把 `PREMIERE_CHECKOUT_ENABLED` 設成 `1`，重新部署。
3. 用測試帳號走到付款頁。下一頁必須顯示 NT$39,800。若看到 NT$399，不要付款，把這個開關關掉。

## 怎麼做一筆金流測試

說明會按鈕不是測試按鈕。它在開關打開後會建立 **NT$39,800** 的正式訂單。

舊的 NT$1 測試仍在 Sites 後端，沒有掛到 Vercel 上。請沿用原本的測試入口（環境變數名稱是 `PAYUNI_TEST_ACCESS`，路徑是 Sites 上的 `/api/payuni/test/create`）。不要用說明會頁面去做 NT$1 測試。

這版沒有另做統一金流的沙盒開關。

## 還需要 Elsa 確認

- 所有標成【待 Elsa 確認】的標題、說明、退費與條款。
- 影片實際長度，以及購買按鈕要在幾點出現。
- 正式課程在統一金流頁上顯示的商品名稱（patch 裡的 `fullcourse` 名稱目前也是待確認）。

- 付款成功信。NT$399 那封沒有改。NT$39,800 那封已在舊後端 patch 裡，但句子仍是【待 Elsa 確認】。定稿前不要打開付款。
- Bunny 影片編號與 CDN 網址。
